# Типы моделей в ансамбле: простое объяснение

## 📚 Введение

В данном исследовании используется **ансамбль из трёх нейронных сетей**, каждая из которых решает задачу детекции AI-текстов своим способом. Ниже приведено простое объяснение принципов работы каждого типа моделей, подходящее для включения в дипломную работу.

---

## 1. Detection-модели (Модели бинарной классификации)

### 1.1 Что это такое?

**Detection-модель** — это нейронная сеть, которая отвечает на вопрос: *«Этот текст написан человеком или искусственным интеллектом?»*

**Аналогия из жизни:** Представьте преподавателя, который проверяет студенческие работы. Он читает текст и по определённым признакам (стиль, сложность предложений, характерные ошибки) определяет, написал ли студент работу сам или скопировал из интернета. Detection-модель работает похожим образом, только анализирует текст математически.

### 1.2 Какие модели использовались?

| Модель | Описание | Размер |
|--------|----------|--------|
| **T-lite-7B** | Русскоязычная языковая модель | 7 миллиардов параметров |
| **Qwen2.5-7B-Instruct** | Многоязычная модель с инструкциями | 7 миллиардов параметров |

### 1.3 Как они обучаются?

**Шаг 1: Подготовка данных**

Берётся датасет, в котором есть:
- Тексты, написанные **людьми** (метка: `0` = human)
- Тексты, написанные **AI-моделями** (метка: `1` = AI)

В нашем исследовании: **1,957 текстов для обучения** и **491 текст для проверки**.

**Шаг 2: Предобучение (Pre-training)**

Обе модели уже были **предобучены** на миллионах текстов из интернета. Это значит, что они уже умеют:
- Понимать структуру языка
- Распознавать грамматические конструкции
- Анализировать смысл предложений

**Аналогия:** Как студент, который уже прочитал тысячи книг и хорошо знает язык, прежде чем научиться определять плагиат.

**Шаг 3: Дообучение (Fine-tuning)**

Мы **дообучаем** модели на нашем специальном датасете с AI-текстами. При этом:
- Модель читает текст
- Пытается угадать: человек или AI написал
- Сравнивает свой ответ с правильной меткой
- Если ошиблась — корректирует свои «веса» (параметры)

**Математически:** Минимизируется функция потерь (loss function), которая показывает, насколько предсказания модели отличаются от правильных ответов.

**Шаг 4: Использование LoRA/QLoRA**

Полное переобучение 7-миллиардной модели требует огромных вычислительных ресурсов. Поэтому мы используем технику **LoRA (Low-Rank Adaptation)**:

- **Основная модель «замораживается»** — её параметры не меняются
- **Добавляются маленькие «адаптеры»** — дополнительные слои, которые обучаются
- Обучается только **~1-2% параметров** вместо 100%

**Аналогия:** Представьте, что у вас есть готовый автомобиль (предобученная модель). Вместо того чтобы переделывать весь двигатель, вы добавляете небольшой тюнинг-кит (LoRA-адаптеры), который улучшает конкретные характеристики.

**QLoRA** — это улучшенная версия LoRA, которая использует **квантование** (сжатие чисел) для ещё большей экономии памяти.

**Шаг 5: DoRA (Weight-Decomposed Low-Rank Adaptation)**

**DoRA** — это дальнейшее улучшение LoRA. Она разлагает веса модели на две части:
- **Направление** (direction) — куда смотрит вектор весов
- **Величина** (magnitude) — насколько он «сильный»

Это позволяет модели обучаться более точно и стабильно.

### 1.4 Как модель делает предсказание?

После обучения модель работает так:

```
Входной текст → [Нейронная сеть] → Число от 0 до 1 → Интерпретация
                                           ↓
                                    Если > 0.5 → AI
                                    Если < 0.5 → Человек
```

**Пример:**
- Текст: «Солнце взошло над горизонтом»
- Модель выдаёт: `0.15` → **Человек** (уверена на 85%)
- Текст: «В свете утренней зари горизонт окрасился багрянцем»
- Модель выдаёт: `0.92` → **AI** (уверена на 92%)

## 2. Embedding-модель (Модель векторных представлений)

### 2.1 Что это такое?

**Embedding-модель** — это нейронная сеть, которая преобразует текст в **вектор** (набор чисел). Тексты с похожим смыслом получают похожие векторы.

**Аналогия из жизни:** Представьте библиотеку, где книги расставлены не по алфавиту, а по темам. Все детективы стоят рядом, все учебники по физике — в другом углу. Embedding-модель делает то же самое: она «расставляет» тексты в многомерном пространстве так, чтобы похожие тексты оказались рядом.

### 2.2 Какая модель использовалась?

| Модель | Описание | Размер вектора |
|--------|----------|----------------|
| **USER-bge-m3** | Современная русскоязычная embedding-модель | 1024 числа |

### 2.3 Как она обучается?

**Шаг 1: Подготовка триплетов**

Для обучения используются **триплеты** — группы из трёх текстов:

- **Anchor (Якорь)** — текст, написанный человеком
- **Positive (Позитивный)** — AI-текст **того же автора** (на ту же тему)
- **Negative (Негативный)** — AI-текст **другого автора** (на другую тему)

**Пример триплета:**
```
Anchor:    «Вчера я ходил в магазин за продуктами» (человек, тема: покупки)
Positive:  «Вчера пользователь посетил торговую точку для приобретения продуктов питания» (AI, тема: покупки)
Negative:  «Квантовые вычисления представляют собой новую парадигму обработки информации» (AI, тема: технологии)
```

**Шаг 2: Контрастивное обучение (Contrastive Learning)**

Модель учится:
- **Приближать** векторы Anchor и Positive (потому что они связаны)
- **Отдалять** векторы Anchor и Negative (потому что они не связаны)

**Математически:** Используется **MultipleNegativesRankingLoss** — функция потерь, которая минимизирует расстояние между Anchor и Positive и максимизирует расстояние между Anchor и Negative.

**Аналогия:** Представьте, что вы учите ребёнка различать породы собак. Вы показываете ему фото лабрадора (Anchor), такое же фото лабрадора в другом ракурсе (Positive) и фото кошки (Negative). Ребёнок учится понимать, что лабрадор похож на лабрадора, но не похож на кошку.

**Шаг 3: Matryoshka Representation Learning**

Это техника, которая позволяет модели работать с векторами **разной длины**. Модель учится кодировать важную информацию в первых числах вектора, а менее важную — в последних.

**Аналогия:** Как матрёшка, где самая важная информация — в маленькой внутренней кукле, а менее важная — во внешних.

### 2.4 Как модель делает предсказание?

После обучения модель работает так:

```
1. Берётся текст → [Embedding-модель] → Вектор (1024 числа)

2. Для классификации:
   - Вектор нового текста сравнивается с векторами из обучающей выборки
   - Находятся ближайшие соседи (K-Nearest Neighbors)
   - Если большинство соседей — AI-тексты → предсказание: AI
   - Если большинство соседей — человеческие тексты → предсказание: Человек
```

**Пример:**
```
Вектор нового текста: [0.12, -0.45, 0.78, ..., 0.33] (1024 числа)

Ближайшие соседи:
- Вектор 1: [0.11, -0.44, 0.77, ...] → AI (расстояние: 0.02)
- Вектор 2: [0.13, -0.46, 0.79, ...] → AI (расстояние: 0.03)
- Вектор 3: [0.50, -0.20, 0.10, ...] → Человек (расстояние: 0.55)

Результат: 2 из 3 соседей — AI → Предсказание: AI
```

## 3. Ансамбль моделей

### 3.1 Что такое ансамбль?

**Ансамбль** — это комбинация нескольких моделей, которые работают вместе для принятия решения.

**Аналогия из жизни:** Представьте комиссию из трёх экзаменаторов, которые проверяют одну работу. Каждый экзаменатор ставит свою оценку, а итоговая оценка вычисляется как среднее (или взвешенное среднее) их оценок.

### 3.2 Почему ансамбль работает лучше?

Каждая модель имеет свои **сильные и слабые стороны**:

| Модель | Сильные стороны | Слабые стороны |
|--------|-----------------|----------------|
| **Qwen2.5-7B** | Высокая точность, понимает контекст | Медленная, требует много памяти |
| **T-lite-7B** | Быстрая, компактная | Менее точная |
| **USER-bge-m3** | Хорошо находит похожие тексты | Не понимает глубокий контекст |

Когда модели объединяются, они **компенсируют недостатки друг друга**:
- Если одна модель ошибается, другие могут это исправить
- Ансамбль более устойчив к шуму и выбросам

### 3.3 Как работает ансамбль в нашем исследовании?

**Шаг 1: Каждая модель выдаёт свою оценку**

```
Текст → Qwen2.5-7B → 0.95 (AI)
Текст → T-lite-7B   → 0.60 (AI)
Текст → USER-bge-m3 → 0.85 (AI)
```

**Шаг 2: Взвешенное усреднение**

Каждая модель имеет **вес**, который показывает, насколько мы ей доверяем:

| Модель | Вес |
|--------|-----|
| Qwen2.5-7B | 0.45 |
| USER-bge-m3 | 0.34 |
| T-lite-7B | 0.21 |

**Итоговая оценка:**
```
0.95 × 0.45 + 0.60 × 0.21 + 0.85 × 0.34 = 0.4275 + 0.126 + 0.289 = 0.8425
```

**Шаг 3: Принятие решения**

```
Если итоговая оценка > 0.5 → AI
Если итоговая оценка < 0.5 → Человек

В нашем примере: 0.8425 > 0.5 → Предсказание: AI
```

### 3.4 Результаты ансамбля

| Метрика | Значение |
|---------|----------|
| **ROC-AUC** | 1.0000 |
| **Accuracy** | 1.0000 |
| **Precision** | 1.0000 |
| **Recall** | 1.0000 |
| **F1-score** | 1.0000 |

**Интерпретация:** Ансамбль правильно классифицировал **все 491 текстов** из проверочной выборки.

## 4. Сравнение типов моделей

| Характеристика | Detection-модели | Embedding-модель |
|----------------|------------------|------------------|
| **Тип задачи** | Бинарная классификация | Векторное представление |
| **Выход модели** | Число от 0 до 1 | Вектор из 1024 чисел |
| **Обучение** | С учителем (метки: 0/1) | Контрастивное (триплеты) |
| **Скорость** | Медленнее (7 млрд параметров) | Быстрее (меньше параметров) |
| **Точность** | Высокая | Средняя |
| **Память** | Требует много GPU | Требует меньше GPU |

## 5. Выводы

1. **Detection-модели** (T-lite-7B, Qwen2.5-7B) работают как «классификаторы» — они напрямую отвечают на вопрос «AI или человек?». Они обучаются на размеченных данных с использованием техник LoRA/QLoRA+DoRA для эффективного дообучения.

2. **Embedding-модель** (USER-bge-m3) работает как «поисковая система» — она преобразует тексты в векторы и находит похожие. Она обучается на триплетах с использованием контрастивного лосс-функции.

3. **Ансамбль** объединяет сильные стороны обоих подходов, достигая идеальных метрик на проверочной выборке.

4. **Ключевое преимущество** такого подхода — возможность детектировать AI-тексты даже от тех моделей, которые не были представлены в обучающей выборке (благодаря embedding-модели, которая ищет структурное сходство).

## 6. Глоссарий терминов

| Термин | Определение |
|--------|-------------|
| **Нейронная сеть** | Математическая модель, вдохновлённая работой мозга, состоящая из слоёв «нейронов» |
| **Параметры** | Числа, которые модель настраивает в процессе обучения (веса связей между нейронами) |
| **Предобучение** | Обучение модели на больших данных перед специализацией на конкретной задаче |
| **Дообучение (Fine-tuning)** | Дополнительное обучение предобученной модели на специализированных данных |
| **LoRA** | Метод эффективного дообучения, при котором обучаются только маленькие «адаптеры» |
| **QLoRA** | Улучшенная LoRA с квантованием (сжатием) весов для экономии памяти |
| **DoRA** | Улучшение LoRA с разложением весов на направление и величину |
| **Embedding** | Векторное представление текста (набор чисел, кодирующий смысл) |
| **Контрастивное обучение** | Метод обучения, при котором модель учится различать похожие и непохожие объекты |
| **Триплет** | Группа из трёх объектов: якорь, позитивный пример, негативный пример |
| **Ансамбль** | Комбинация нескольких моделей для улучшения точности предсказаний |
| **ROC-AUC** | Метрика качества классификации (1.0 = идеальное разделение классов) |
| **Accuracy** | Доля правильных ответов модели (1.0 = 100% правильных) |
| **Precision** | Доля истинно положительных среди всех предсказанных как положительные |
| **Recall** | Доля найденных положительных среди всех реально положительных |
| **F1-score** | Среднее гармоническое между Precision и Recall |
